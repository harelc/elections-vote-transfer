איך מחברים

ב-Claude: Settings, אחר כך Connectors, מוסיפים connector ומדביקים את הכתובת. אם מבקשים טוקן, משאירים ריק.

ב-Cursor: Settings, אחר כך MCP, ומוסיפים שרת עם הכתובת למעלה. אין צורך בכותרת אימות.

ב-Claude Code, מהטרמינל: claude mcp add --transport http kolot https://kolot-nodedim.netlify.app/mcp

אחר כך שואלים. הצ׳אט בוחר לבד איזה נתון לבקש.

יש תקרה לדקה ולכל היום, כדי שהפונקציה לא תרוקן את תקציב האתר. אם היא נגמרת, הצ׳אט מקבל בקשה לחכות.

שאלות שאפשר להעתיק

נדידת קולות היא אומדן, לא ספירת אנשים. רווח בר-הסמך הוא 95%. כנסת 26 היא תרחיש מדומה. t-SNE אינו מפה של ישראל.

Paste one address into your own chat and ask in Hebrew or English. Your chat pays for the answer. This site does not call a model.

https://kolot-nodedim.netlify.app/mcp

Connect it

In Claude: Settings, then Connectors, add a connector and paste the address. If it asks for a token, leave it blank.

In Cursor: Settings, then MCP, and add a server with the address above. No authorization header is required.

In Claude Code, from a terminal: claude mcp add --transport http kolot https://kolot-nodedim.netlify.app/mcp

Then ask. The chat decides which figure to fetch.

There is a per-minute cap and a daily cap, so the function cannot run down the site’s budget. Past the cap, the chat is asked to wait.

Questions you can copy

A vote transfer is an estimate, not a count of people. The interval is 95%. Knesset 26 is simulated. t-SNE is not a map of Israel.
