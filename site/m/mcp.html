🏠 קולות נודדים · שאל את הנתונים

מדביקים כתובת אחת בצ׳אט שלכם ושואלים בעברית או באנגלית. הצ׳אט שלכם משלם על התשובה. האתר לא קורא למודל.

https://kolot-nodedim.netlify.app/mcp

איך מחברים

Claude

Settings, אחר כך Connectors. מוסיפים connector ומדביקים את הכתובת. אם מבקשים טוקן, משאירים ריק.

Cursor

Settings, אחר כך MCP. מוסיפים שרת עם הכתובת למעלה. אין צורך בכותרת אימות.

Claude Code

מהטרמינל:

claude mcp add --transport http kolot https://kolot-nodedim.netlify.app/mcp

אחר כך שואלים. הצ׳אט בוחר לבד איזה נתון לבקש. יש תקרה לדקה ולכל היום. אם היא נגמרת, הצ׳אט מקבל בקשה לחכות.

שאלות לדוגמה שאפשר לשאול

נדידת קולות היא אומדן, לא ספירת אנשים. רווח בר-הסמך הוא 95%. כנסת 26 היא תרחיש מדומה. t-SNE אינו מפה של ישראל.

Paste one address into your own chat and ask in Hebrew or English. Your chat pays for the answer. This site does not call a model.

https://kolot-nodedim.netlify.app/mcp

Connect it

Claude

Settings, then Connectors. Add a connector and paste the address. If it asks for a token, leave it blank.

Cursor

Settings, then MCP. Add a server with the address above. No authorization header is required.

Claude Code

From a terminal:

claude mcp add --transport http kolot https://kolot-nodedim.netlify.app/mcp

Then ask. The chat decides which figure to fetch. There is a per-minute cap and a daily cap. Past the cap, the chat is asked to wait.

Example questions you can ask

A vote transfer is an estimate, not a count of people. The interval is 95%. Knesset 26 is simulated. t-SNE is not a map of Israel.
