שאל את הנתונים

מדביקים כתובת אחת בצ׳אט שלכם, ושואלים בעברית או באנגלית. הצ׳אט שלכם משלם על התשובה. האתר לא קורא למודל ולא גובה תשלום.

https://kolot-nodedim.netlify.app/mcp

איך מחברים

Claude

פותחים Settings, אחר כך Connectors, ומוסיפים connector. מדביקים את הכתובת. אם מבקשים טוקן, משאירים אותו ריק.

Cursor

פותחים Settings, אחר כך MCP, ומוסיפים שרת שהכתובת שלו היא הכתובת למעלה. אין צורך בכותרת אימות.

Claude Code

מהטרמינל:

claude mcp add --transport http kolot https://kolot-nodedim.netlify.app/mcp

אחר כך שואלים בעברית או באנגלית. הצ׳אט בוחר לבד איזה נתון לבקש. יש תקרה לדקה ולכל היום, כדי שהפונקציה לא תרוקן את תקציב האתר. אם היא נגמרת, הצ׳אט מקבל בקשה לחכות.

שאלות לדוגמה שאפשר לשאול

הנדידה בין בחירות היא אומדן ארצי, לא ספירת אנשים. כשיש רווח בר-סמך, הוא של 95% מבוטסטראפ של קלפיות. כנסת 26 היא תרחיש מדומה. מרחקים ב-t-SNE משמעותיים רק בין קלפיות קרובות, וזו לא מפה של ישראל. מחשבון המנדטים והבחירות האזוריות לא כלולים כאן.

Paste one address into your own chat and ask in Hebrew or English. Your chat pays for the answer. This site does not call a model and does not charge you.

https://kolot-nodedim.netlify.app/mcp

Connect it

Claude

Open Settings, then Connectors, and add a connector. Paste the address. If it asks for a token, leave that blank.

Cursor

Open Settings, then MCP, and add a server whose URL is the address above. No authorization header is required.

Claude Code

From a terminal:

claude mcp add --transport http kolot https://kolot-nodedim.netlify.app/mcp

Then ask in Hebrew or English. The chat decides which figure to fetch. There is a per-minute cap and a daily cap, so the function cannot run down the site’s budget. Past the cap, the chat is asked to wait.

Example questions you can ask

A transfer between elections is a national estimate, not a count of people. When a confidence interval is present, it is a 95% ballot bootstrap. Knesset 26 is a simulated scenario. t-SNE distance matters only among nearby ballots, and it is not a map of Israel. The seat calculator and the regional simulator are not included.
